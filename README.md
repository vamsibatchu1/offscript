# Offscript

Most digital type is the same hand, copied forever. Perfect outlines. Even spacing. No tremor, no dry ink, no morning where the letters lean a little more than they did last night.

**Offscript** is an experiment in the opposite. It invents a handwritten alphabet from a seed and a handful of parameters — pressure, tremor, bounce, flare — and lets you walk away with a real `.otf`. Each run is a different hand. You can tune it, draw a gesture to shape it, try it on paper textures, then download a font that did not exist an hour ago.

It is not a foundry. It is not a replacement for a drawn typeface. It is a studio for the roughness that usually gets designed out: the scratch, the wobble, the letter that sits a little off the line. If you have ever wanted a handwriting that is yours for a poster, a note, a title — without tracing fifty glyphs by hand — this is the toy for that itch.

This is an experimental project. Expect odd bowls, stubborn Qs, and days when the hand feels more alive than others. That is the point. Have fun with it. Break the sliders. Generate something ugly and something you want to keep.
